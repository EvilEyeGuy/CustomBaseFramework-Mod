# Custom Base Framework

![Make your own settlements](https://raw.githubusercontent.com/EvilEyeGuy/CustomBaseFramework-Mod/workshop/make_your_own.png?v=7)

![Introduction](https://raw.githubusercontent.com/EvilEyeGuy/CustomBaseFramework-Mod/workshop/h1_intro.png?v=1)

Custom Base Framework builds NPC settlements in RimWorld from handmade buildings. Every faction base, from a small village to a walled fortress city or a modern metropolis, is laid out on the terrain of its map, with roads, fields, animal pens, defenders and loot. Hideouts, ruins and crypts become dungeons with several levels.

It ships with ready-made settlements for the base game, Medieval Overhaul, Vanilla Factions Expanded - Medieval 2, Settlers and Classical, The Profaned and BoneReapers ReMarrowed. With the in-game editor you can build your own and save them into your own mod.

Available on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3813689040).

**To get started:** load a test colony, open the mod settings of Custom Base Framework and enable **Editor in the architect menu**. The guide opens from the editor or the mod settings; the same guide is in the mod folder at `Wiki/Open Guide.html`.

![Requirements](https://raw.githubusercontent.com/EvilEyeGuy/CustomBaseFramework-Mod/workshop/h4_requirements.png?v=1)

- RimWorld 1.6 or 1.7
- [Harmony](https://steamcommunity.com/workshop/filedetails/?id=2009463077)

All other mods are optional; their content loads only when they are active. You can add the mod to an existing save: settlements you have already visited stay as they are, new ones are built when you first visit them.

![Roadmap](https://raw.githubusercontent.com/EvilEyeGuy/CustomBaseFramework-Mod/workshop/h7_roadmap.png?v=1)

Released: multi-level dungeons, the Medieval Overhaul cultist hideouts and ruins as dungeons, and crypts below cemeteries and necropolises.

Next: settlement garrisons based on raid points, and a quest editor for modders. No release date yet.
