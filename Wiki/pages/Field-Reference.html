Field reference

Modding

Use this reference to check XML field names, types and initial defaults. Start with the modding guide for complete examples and the relationships between definitions.

The tables are generated from the framework assembly. Defaults describe a newly created definition before inheritance, reference resolution and generation; a blank value may therefore acquire a fallback later. Fields marked optional can inherit a value instead of overriding it.

For maintainers: edit wiki descriptions in Wiki/ReferenceDescriptions.xml; editor tooltips remain in Languages/English/Keyed. Regenerate these pages with WikiGen.cs against the current framework assembly. Quest extensions and quest nodes are documented in Modding quests.

Definitions

  • BuildableRuleDef: Assigns otherwise uncategorised buildings to architect categories when the building-aid setting is enabled.
  • CropListDef: Shares a weighted selection of plants between fields and pens.
  • DungeonProfileDef: Retained definition for dungeon configuration.
  • FactionFlagDef: Assigns flag object lists to a faction.
  • HelpDef: Provides help text for the in-game editor.
  • LootBuildingCategoryDef: Supplies the objects placed by Fill and Object anchors, such as shelves, barrels or market stalls.
  • LootTableDef: Generates item selections for containers, shelves or loose loot.
  • MapStepsDef: Controls which map generation steps are suppressed or gated by tech level on CBF maps.
  • MaterialListDef: Resolves named construction roles into objects, materials, terrain and roofs.
  • PawnListDef: Provides weighted pawn kinds for garrisons, spawn anchors, animal pens and container occupants.
  • PieceCategoryDef: Groups interchangeable pieces and supplies their shared placement rules.
  • PieceDef: Stores a building, wall segment or other reusable structure as character grids and a shared legend.
  • RuinDef: Applies damage and occupation rules to a generated settlement used as a quest site.
  • SettlementPlanDef: Defines the building programme for a settlement: its wards, districts, fortifications and defenders.
  • StyleDef: Identifies a style used when selecting wall profiles, with an optional fallback style.
  • UnitSwapDef: Replaces generic pawn kinds and objects with faction-specific alternatives.
  • WallProfileDef: Defines a repeating wall cross section and optional tower and gatehouse pieces.

Parts used inside definitions

  • Ackerspec: Requests planted fields in a suburb or rural ward.
  • BudgetEntry: Requests a category of buildings or one specific piece within a district.
  • ContentZoneSpec: Configures a connected region in the older PieceDef.content grid.
  • CropEintrag: Adds a plant and its relative selection weight to a CropListDef.
  • Dekospec: Places decorative or defensive pieces along a ward road network.
  • DistrictSpec: Groups building requests within a ward and supplies preferences for their position.
  • Garnisonseintrag: Requests defenders from a pawn list for one ward.
  • Gehegespec: Requests fenced animal pens in the Rural ward.
  • HafenEintrag: Requests a harbour piece or category and its quantity.
  • HafenSpec: Adds harbour buildings near a settlement when a suitable coast or sufficiently wide river is available.
  • LegendEntry: Maps one character in a piece grid to an object, terrain, roof, pawn or anchor.
  • LegendVariant: Adds a weighted alternative to a legend entry.
  • LootEntry: Defines one result in a loot table: a specific item, a random item from a ThingCategoryDef, or another loot table.
  • LootMember: Configures one object in an object list, including its loot override and what happens after its contents are removed.
  • MaterialRole: Defines the candidates for one construction role, optionally restricted to a ward or matching fortification pieces.
  • Minending: Adds an object to a generated mine at its entrance, along a tunnel or in a chamber.
  • Minenspec: Requests mines associated with a district and its buildings.
  • PawnListEntry: Adds one PawnKindDef to a pawn list, with a relative selection weight and an optional Ideology specialist role.
  • PlacementRules: Overrides supported category rules for one PieceDef, including selection weight, wall preference, faction restrictions and ideoligion conditions.
  • Stadtteil: Defines one ward within SettlementPlanDef.wards: Town, Suburb or Rural.
  • Tauscheintrag: Maps a source pawn kind or object to a replacement within a UnitSwapDef.
  • Techschritt: Associates a map generation step with its minimum faction tech level.
  • TerrainWeight: Adds one terrain candidate to a material role terrainMix.
  • Vorfeldspec: Places groups of 1×1 obstacle pieces outside a ward wall or boundary.
  • WallEntry: Selects a piece or category for a ward wall, emplacement or gatehouse list.
