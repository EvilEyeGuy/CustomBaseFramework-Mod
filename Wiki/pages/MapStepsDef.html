MapStepsDef

Modding

Controls which map generation steps are suppressed or gated by tech level on CBF maps. The framework reads the definition named CBF_MapSteps, so extend that definition rather than creating another independently named one.

Define this under a <Defs> root using <CustomBaseFramework.MapStepsDef>. Give it a unique defName; label and description are the common display fields. References from other definitions use the defName.

Field Type Default Meaning
fromTechLevel list of Techschritt none Map generation steps that only run on CBF maps when the map faction reaches the given tech level. Only read from the def named CBF_MapSteps.
suppress list of text none Map generation steps skipped on CBF maps. If CBF builds nothing there, they are run afterwards. Only read from the def named CBF_MapSteps.
