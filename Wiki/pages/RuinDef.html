Field reference / RuinDef

RuinDef

XML node: <CustomBaseFramework.RuinDef>. Also takes the common fields defName, label and description.

Field Type Default Meaning
angriffsseite Rot4 200 Side the attackers came from: North, East, South or West. Breaches and the worst damage gather there. Empty picks a side at random.
besatzung Besatzungsart (Keine, Bauherr, Besatzer) Besatzer Who holds the ruin. Keine leaves it empty, Bauherr keeps the original owners, Besatzer puts the conquering faction in, drawn from raid points only, without ward garrisons or the units set on anchors.
besatzungAnteil number 1 Scales how many defenders the ruin gets. 1 is the full number, 0.5 half of it.
beuteBeiBesatzern number 0 Share of the remaining loot, 0 to 1, that is carried off and piled up on a square near the centre.
beuteFaktor number 1 How much loot remains, 1 keeps all of it. Stacks shrink by this factor, single items survive with this chance.
brandstellen number 0 How likely a room is burnt out, 0 to 1, more often near the attack. Burnt rooms get charred floors and lose flammable contents.
breschen IntRange 0 How many breaches are torn into the outer wall, as a range. They favour the attack side and the gates.
felderVerwuestet number 0 Chance per field cell that its crop is destroyed, 0 to 1.
feuer IntRange 0 How many fires still burn, as a range. They only start in burnt rooms whose walls do not burn.
gebaeudeSchaden FloatRange 0~0 Share of hit points buildings lose, as a range from 0 to 1. Buildings near the attack lose more.
gefangene IntRange 0 How many former inhabitants the occupiers hold prisoner, as a range. Only when besatzung is Besatzer.
geschuetzeZerstoert number 0 How likely a turret is destroyed, 0 to 1, more often near the attack.
haeufung number 0.6 How strongly the damage gathers around the breaches and points of attack, 0 to 1. 0 spreads it evenly.
leichenAngreifer IntRange 0 How many dead attackers lie around, as a range. They have been dead for verwesungTage.
leichenBewohner IntRange 0 How many dead inhabitants lie around, as a range. They have been dead for verwesungTage.
schutt number 0 Rubble on open ground and roads, 0 to 1, thicker near the attack.
torZerstoert number 0 Chance per gate that it is torn down, 0 to 1.
verwesungTage FloatRange 0~0 How long the bodies have been dead, in days, as a range.
viehWeg number 0 Chance per animal of the owners or occupiers that it is gone, 0 to 1.
wandAbriss number 0 How likely a building wall is torn down, 0 to 1, more often near the attack.
