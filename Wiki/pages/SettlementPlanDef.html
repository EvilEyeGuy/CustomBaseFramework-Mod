Field reference / SettlementPlanDef

SettlementPlanDef

XML node: <CustomBaseFramework.SettlementPlanDef>. Also takes the common fields defName, label and description.

Field Type Default Meaning
ankerSoldaten whole number 40 Upper limit on fighters. Once the settlement has this many, further spawn anchors for fighters stay empty; gunner anchors still get theirs. 0 means no limit.
ankerZivil whole number 30 Upper limit on civilians. Once the settlement has this many pawns that are not fighters, further civilian spawn anchors stay empty. 0 means no limit.
anteil
Weight		 number 0 Weight of this settlement type against the other types the same faction may get. 0 counts as 1.
assaultDelayTicks
Assault delay		 whole number 25000 How long the defenders wait before they attack, in ticks.
buchtHaus
Smallest house		 whole number 5 Edge length of the smallest house. Bays narrower than this are dropped.
budget list of BudgetEntry none Which categories the settlement wants, how many of each, and what share of the area.
coreSize
Core size		 IntRange 66~74 Edge length of the settlement core, as a range. Everything else grows around it.
defenderGroupKind
Defender group		 text none Which group kind the defenders come from. Empty means Settlement, then Combat.
defenderPoints
Defender strength		 FloatRange 180~420 How strong the defenders are, as a point range.
defendersOnWall
Defenders on the wall		 number 0.25 What share of the defenders stands on the walkway rather than on the ground.
districts list of DistrictSpec none How many districts this settlement has, and how many entries in total.
embrasureEvery
Embrasure spacing		 whole number 5 Every how many cells the wall gets an embrasure. 0 means none. Without the EMBRASURE role plain wall is used.
emplacements
Defensive positions		 list of WallEntry none Which pieces may serve as towers, gun batteries and the like.
excludeFactions
Excluded factions		 list of text none Factions (FactionDef defName) that never get this settlement type, even when their tags or tech level fit.
factionTags
Factions		 list of text none Which factions may use this settlement type.
fuerAlleFraktionen
For every faction of these levels		 true/false false Also offers this type to factions that have no settlement type of their own, if their tech level is in techLevels.
gatehouses list of WallEntry none Which pieces may serve as gatehouses.
gelaendeOeffnen true/false false Lets the planner choose a site that needs earthwork first, such as rock cleared away. Off by default; the planner still does it as a last resort.
hafen HafenSpec none Harbor at the coast or on a wide river: which harbor buildings the settlement gets. Only for medieval settlements.
kerbeMax
Maximum notch		 whole number 6 How deep the outline may cut inwards where the terrain calls for it.
kind
Settlement kind		 Ortsart (Mittelalterstadt, Modernestadt, Lager, Verlies) Mittelalterstadt On a settlement type: Mittelalterstadt or Modernestadt. Modernestadt allows roads up to 6 wide and lays power conduits. Lager and Verlies are switched off at the moment. On a pawn list entry: the pawn kind (PawnKindDef defName).
laufMax
Longest wall run		 whole number 6 Longest straight piece of wall before it must step.
laufMin
Shortest wall run		 whole number 1 Shortest straight piece of wall before it may turn.
mapSize
Map size		 whole number 175 How large the map is that this settlement is generated on.
materialList
Material list		 MaterialListDef none Which material list this settlement type uses for walls, floors, doors, gates and the other roles.
maxBuildingGap
Largest gap between buildings		 whole number 0 Keeps enough room between houses for a path.
minBuildingGap
Smallest gap between buildings		 whole number 0 0 lets the framework decide from the loaded mods.
minFuellgrad
Minimum fill		 number 0.85 How full the outline must be against its convex hull. Lower allows more ragged shapes.
minLobe
Smallest bulge		 whole number 5 Smallest usable bulge of the outline. 0 turns the check off.
requiredMods
Needs these mods		 list of text none Mods this settlement type needs beyond those the editor detects. The editor adds them to the dependencies when packaging. The game does not read the list.
roadLane
Lane width		 whole number 1 Width of the side lanes.
roadMain
Main road width		 whole number 2 Width of the main road. There are only two widths on purpose; more cuts the map up visually.
siteTags list of text none Tags that make this settlement type usable for quest sites. A site that asks for tags only takes types with a matching one. Empty means it is never used for sites.
stufeMax
Largest step		 whole number 3 How far the wall may step sideways at once.
style StyleDef none Old field. It only still picks the wall profile and the standard materials. Does not restrict piece selection.
styles list of StyleDef none Old field. It only still picks the wall profile and the standard materials. Does not filter pieces.
suburbIslands whole number 0 How many separate suburb areas grow outside the town, at most one per open map side. 0 turns this off.
targetBuilt
Target built share		 number 0 How densely built the settlement should feel. Hand-built MO settlements sit at 0.61.
techLevels
Tech levels		 list of TechLevel (Undefined, Animal, Neolithic, Medieval, Industrial, Spacer, Ultra, Archotech) none Tech levels this type is meant for. With fuerAlleFraktionen they decide which factions qualify. Pawns from pawn lists are capped at the faction's level if it is listed, otherwise at the highest listed one. Empty means no cap.
towerCapTotal
Tower limit		 whole number 0 Upper limit on towers. 0 means as many as there are corners.
towerCorner
Corner tower size		 whole number 7 Edge length of a corner tower, measured on the centre line of the wall band.
towerCurtain
Curtain tower size		 whole number 7 Edge length of the towers that sit between the corners.
towerRun
Straight run before a tower		 whole number 6 How much straight wall must run before a tower may be placed.
towerSpacing
Tower spacing		 whole number 24 How far apart curtain towers stand. Larger means fewer towers.
wallGap
Gap to the wall		 whole number 1 How much room stays free inside the wall. Only pieces with wallContact may come closer.
walls list of WallEntry none Wall strips, each one cell wide or one cell high, repeated along the wall by weight. The thickest decides how deep the wall is. On a ward, empty means no wall. On the settlement type they replace the strips of the wall profile.
wards list of Stadtteil none The parts of the settlement: Stadt, Vorstadt and Umland, each with its own wall, garrison, districts and surfaces.
wdStufe IntRange 0 World Domination tier this type stands for, as a range from 1 to 4. A settlement with a tier prefers the types closest to it. 0 means no tier.
wdTyp list of text none World Domination settlement types this plan stands for, such as Mining or Slavery. Empty means any type. Only used with World Domination 2.0.
weightHilly
Prefers hills		 number 0 How strongly this settlement type wants hilly terrain.
weightNearRoad
Prefers roads		 number 1 How strongly this settlement type wants to sit near a road on the world map.
weightNearWater
Prefers water		 number 0 How strongly this settlement type wants to sit near water.
worldTexture
World map icon		 text none Image of this settlement on the world map when zoomed in. It is tinted in the faction colour.

All images in Textures/World/WorldObjects/CBF can be chosen, including those of other mods.
